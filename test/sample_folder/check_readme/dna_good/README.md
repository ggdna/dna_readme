# dna_sample

English | [Deutsch](README.de.md)

The DNA layer that gives a repo a sample guide.

## Motivation

Every repo needed the same sample guide.

## Usage

```bash
dart pub add dev:dna_sample
helix init
```

## Guides

- `dna/doc/guides/sample-guide.md` — how to write samples

## Skills

- `/sample` — writes a sample

## Scripts

- `dna/scripts/functions/` — the shared functions

## Layers

Orthogonal: it carries only its own topic.

## Variables

- `dnaSampleOrg` — the organization of the samples

## Development

Run `dart test` after changes.
