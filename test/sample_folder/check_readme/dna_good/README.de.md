# dna_sample

[English](README.md) | Deutsch

Der DNA-Layer, der einem Repo einen Beispiel-Guide gibt.

## Motivation

Jedes Repo brauchte denselben Beispiel-Guide.

## Verwendung

```bash
dart pub add dev:dna_sample
helix init
```

## Guides

- `dna/doc/guides/sample-guide.md` — wie man Beispiele schreibt

## Skills

- `/sample` — schreibt ein Beispiel

## Skripte

- `dna/scripts/functions/` — die gemeinsamen Funktionen

## Layer

Orthogonal: Er trägt nur sein eigenes Thema.

## Variablen

- `dnaSampleOrg` — die Organisation der Beispiele

## Entwicklung

Nach Änderungen `dart test` ausführen.
